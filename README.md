# KVFocus: A Perturbation-Theoretic Token-Risk Score for Selective KV Cache Reuse in RAG

NeurIPS 2026.

This repository contains the CacheFlex framework and the KVFocus selector,
implemented as a patch on top of [SGLang](https://github.com/sgl-project/sglang) v0.5.5.post3.

Evaluation scripts, benchmark runners, configuration files, and documentation
will be released incrementally in upcoming updates.
